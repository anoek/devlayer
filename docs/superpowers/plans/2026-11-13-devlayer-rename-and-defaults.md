# devlayer Rename and New Defaults Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the project from `sandbox` to `devlayer` (user-facing, then internal), then make the agent-friendly behavior the default: a new layer per run, the cwd bound live, host network, audio, and LLM tool binds; `--join` replaces `--name`; directory-aware `--last`.

**Architecture:** Two no-behavior-change rename passes, then one task per behavior change. Layer selection moves from "always resolve `name`" to a `LayerSelection` that is chosen from the CLI, env, config and the action. The layer's directory and whether that directory was bound are stored in `settings.json`, and are reused on re-entry and on restart.

**Tech Stack:** Rust (clap, serde/serde_json, toml, anyhow, rstest), OverlayFS, Linux namespaces, setuid binary; tests run under `sudo` via `make test` / `TEST=name make quick-test`.

**Spec:** `docs/superpowers/specs/2026-11-13-devlayer-rename-and-defaults-design.md`. Read it before starting any task.

## Global Constraints

- Clean switchover: no fallback, alias or migration for any `sandbox` name, path, env var or config file.
- New names: binary `devlayer`; storage `~/.devlayer/`, fallback `/tmp/devlayer-<uid>`; env `DEVLAYER_*`; project config `.devlayer.conf` / `.devlayer.toml`; user config `~/.config/devlayer/config.(conf|toml)`; system config `/etc/devlayer.(conf|toml)`.
- Test layer name prefixes: `devlayer-coverage-*`, `devlayer-bind-empty-*`. New test files go in `tests/ai_test_*.rs` (per CLAUDE.md).
- The ephemeral layer name format stays `ephemeral_%Y-%m-%d_%H-%M-%S[.<ms>]`.
- Bind layer order (lowest to highest): system defaults + audio → LLM binds → cwd bind → config files → env → CLI.
- Every task ends with `cargo fmt`, `cargo clippy` clean, and the touched tests passing via `TEST=<name> make quick-test`. Tasks 1, 2 and 9 also run the full `make test`.
- Coverage must stay at 100% (`make coverage-check`); any new `#[cfg(feature = "coverage")]` test hooks follow the existing `TEST_*` env-var pattern.

## Review Focus

1. **Running `devlayer` from a subdirectory of the directory where a layer was created, with `--last`.** The layer must be entered with its original directory bind, not fail with "bind mounts changed". Test: Task 7, `ai_test_cwd_bind_reenter_from_subdir`.
2. **`devlayer status` in a project dir right after an agent ran.** It must show changes outside the project (whole layer), not an empty list. Test: Task 9, `ai_test_status_default_whole_layer`.
3. **Bare `devlayer accept` / `reject`.** These must refuse with a hint, and must change nothing. Test: Task 9, `ai_test_accept_requires_pattern` (asserts the file is still in the layer afterwards).
4. **Two layers created in the same directory.** `--last` must pick the newer one; a layer created in a deeper directory must not be chosen when you stand in its parent. Test: Task 8, `ai_test_last_nearest_ancestor_and_newest`.
5. **A path in the LLM list that is missing on the host** (most users have only one or two agents). It must be skipped silently, not fail canonicalization. Test: Task 6, unit test `llm_binds_skip_missing_paths`.

**Interfaces:**
- Consumes: `LayerSettings::load_from_file`, `LayerSettings.created_in` (Task 7).
- Produces:
  - `enum LayerSelection { New, Last, Join(String) }`
  - `fn default_selection(action: Option<&Action>) -> LayerSelection` behaves like this:
    - `None` → `New`;
    - `Status`, `Diff`, `Accept`, `Reject` → `Last`;
    - `Stop { all: false, patterns: None }` and `Delete { patterns: None|Some(empty) }` → `Last`;
    - `Stop` with `all` or patterns, `Delete` with patterns, `List`, `Sync`, `Clean`, `Config` → `New` *without failing*.
    - For `Config`, try `Last` first and fall back to `New` if nothing matches, so `devlayer config name` reports this directory's layer.
  - Precedence: `--join`/`--new`/`--last` CLI > `DEVLAYER_JOIN` > config `join` > `default_selection`.
  - `fn find_last_layer(storage_dir: &Path, cwd: &Path) -> Result<String>`: for each ancestor `A` of canonical `cwd` (itself first, `/` last), collect the layers whose `settings.json` has `created_in == A`. At the first non-empty set, return the newest by dir creation time (`metadata.created()` falling back to `modified()`, as today). Layers without settings or without `created_in` are ignored. If nothing matches → `"No devlayer found for {cwd} or its parent directories; use --join <name> or `devlayer list`"`.
  - The existing `TEST_LAST_IS_EMPTY` coverage hook is kept.
